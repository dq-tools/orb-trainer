# 虹色のオーブ 鍛冶トレーナー

ドラゴンクエストX の道具鍛冶「虹色のオーブ」を練習するためのシミュレータです。
学習した AI（評価関数＋終盤の厳密解）が、毎手「次の一手」と「大成功の見込み」を教えてくれます。

- **サーバー不要**。AI も局の進行も、ブラウザの中で Python（[Pyodide](https://pyodide.org/)）が動きます。GitHub Pages にそのまま置けます
- **シミュ**: 局を打って練習する。「AI の一手を打つ」「最後まで AI」で手本も見られる
- **実機モード**: 実際のゲームの盤面（温度・集中・各マスの値・本会心済・必殺）を入れて、推奨だけ聞く
- 棋譜と進行中の局は、その端末のブラウザ（localStorage）にだけ保存されます。棋譜は TSV で書き出せます

## 使い方（公開）

1. このフォルダをそのまま GitHub のリポジトリにする（ルートに `index.html` がある状態）
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にする
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

手元で確かめる時は、どれかの HTTP サーバーで配信してから開きます（`file://` では Web Worker と fetch が動きません）。

```bash
python -m http.server 8765
# → http://localhost:8765/
```

初回は Pyodide 本体と numpy（合わせて十数 MB）を CDN（jsdelivr）から読み込むので 10〜20 秒かかります。2 回目からはブラウザのキャッシュで速く開きます。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面。盤面・特技ボタン・AI の提案・記録・実機モード |
| `worker.js` | Web Worker。Pyodide を起動し、`py/` の Python と `model.npz` を読み込んで `orb_core` の関数を呼ぶ |
| `py/orb_core.py` | 局の進行（new_game / move / undo / finish / restore）と AI の推奨（ai / advise）。JS とは JSON 文字列でやり取り |
| `py/kaji_sim.py` `py/kaji_data.py` | 鍛冶ミニゲームのシミュレータ（温度別のダメージ表・会心・再生・必殺・大成功の判定） |
| `py/kaji_feat.py` `py/value_net.py` `py/value_policy.py` | 学習型 AI。局面を特徴に直し、評価関数（小さな MLP、numpy 推論）で「その手を打った後の大成功の確率」を見積もる。1 マス・2 マスの技は出目×会心を全部数え上げる |
| `py/endgame_solver.py` | 終盤（残り集中 50 以下・未確定 4 マス以下）の厳密解。全分岐を数え上げて大成功の確率を最大にする手を返す |
| `py/finish_lookahead.py` `py/run_amatsuyu.py` | 上の 2 つが使う共通部品（候補手・窓の計算など） |
| `py/recipes.json` `py/recipes.py` | 虹色のオーブの基準値（A 85-95 / B 140-148 / C 115-121 / D 140-148 / E 115-121 / F 85-95、地金は再生）。出典は [meluce.jp](https://meluce.jp/flyby/dqx/) |
| `model.npz` | 評価関数の重み。シミュレータ上の自己対局で学習したもの（1000 局の大成功率 81.6%、手書きの定石 AI は 74%） |

## 前提（シミュレータの仕様）

- 職人 Lv80・光の鍛冶ハンマー★3（会心 +4.6%・集中 +45）・開始の集中力 253・道具会心率 6.2%（ねらい系は 7 倍）
- 理想値（基準値のどこで止まるか）は範囲内で毎回ランダム。大成功は誤差合計 7 以下。範囲をはみ出したマスは 9 扱い（1 か所でもはみ出すと大成功しない）
- 再生: 打った後の温度が 200℃ の倍数になると、範囲に入っていないマスのうち割合がいちばん進んだマスが 12〜16 戻る
- AI の「見込み」はこのシミュレータ上の推定で、実機の率を保証するものではありません

## 広告を入れる

`index.html` の `<!-- ▼ 広告: … -->` 〜 `<!-- ▲ 広告: … -->` の間を差し替えます（head / TOP / SIDE×2 / BOTTOM）。
差し替えるまでは点線の枠が出ます。枠ごと消してもレイアウトは崩れません。

公開したら、`index.html` の末尾にある「ソースコード（GitHub）」のリンク先（`id="ghLink"`）をリポジトリの URL に変えてください。

## 更新する時

`py/` の中身や `model.npz` を変えたら、`worker.js` と `app.js` と `index.html` の `VERSION`（`?v=…`）を変えてください。ブラウザのキャッシュが新しいファイルを取りに行きます。
